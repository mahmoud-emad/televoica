# Televoica v0.2.0 — much more accurate transcriptions

## Summary

- Transcription now uses Whisper large-v3 (the most accurate open-source speech model), so text matches your voice notes much more closely
- Fewer made-up words and repeated phrases, especially around silence and background noise
- Better results in Arabic and other non-English languages
- You'll get a short note like this one after every update

## Details

### Accuracy
- New default engine: [faster-whisper](https://github.com/SYSTRAN/faster-whisper) running `large-v3` (previously `base` on openai-whisper).
- Beam search (width 5), temperature fallback and `condition_on_previous_text=False` to stop repetition loops.
- Voice-activity detection skips silence, which removes most hallucinated text.
- Optional vocabulary prompt (`STT_WHISPER_INITIAL_PROMPT`) so names and technical terms are spelled correctly.
- Set `STT_WHISPER_LANGUAGE` (for example `ar` or `en`) to skip language auto-detection, the most common cause of wrong output.

### Release announcements
- The bot keeps a small user database (SQLite: Telegram name, username, language, first/last seen, request count, plus a log of requests, never audio or text) and sends a short summary of each new release once, right after it restarts on the new version.
- The full notes are published as a GitHub Release by the `Release` workflow.

### Configuration
- New settings: `STT_WHISPER_COMPUTE_TYPE`, `STT_WHISPER_INITIAL_PROMPT`, `STT_WHISPER_BEAM_SIZE`, `STT_WHISPER_VAD_FILTER`, `STT_DATA_DIR`, `STT_ANNOUNCE_RELEASES`, `STT_REPO_URL`.
- Defaults changed: `STT_PROVIDER=faster_whisper`, `STT_WHISPER_MODEL=large-v3`, `STT_WHISPER_DEVICE=auto`.
- The legacy `whisper` and `google_cloud` providers still work.

### Upgrade notes
- First start downloads the ~3 GB model; docker-compose caches it in a volume.
- On a CPU, large-v3 is slower than `base`. Use `STT_WHISPER_MODEL=large-v3-turbo` for a big speedup with a small accuracy trade-off.
- Mount a persistent volume at `STT_DATA_DIR` (docker-compose does this) so the bot keeps its user database (`televoica.db`) across restarts.
- `televoica users` lists everyone the bot knows; `python scripts/backfill_users.py <bot.log>` imports users and requests from an old log.
